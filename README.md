# DLAA-VR: Neural Supersampling with Cross-Eye Reprojection

Source code for evaluating neural supersampling techniques for VR. 

This project reproduces the core of *"Efficient neural supersampling for a novel gaming dataset"* and extends its approach by introducing **cross-eye reprojection** to test its viability as an auxiliary information source.

*A. Mercier, Ruan Erasmus, Y. Savani, M. Dhingra, F. Porikli, and G. Berger, ‘Efficient neural supersampling on a novel gaming dataset’, Aug. 03, 2023, arXiv: arXiv:2308.01483. doi: 10.48550/arXiv.2308.01483.

Note: this is the original research code used for my dissertation. It is provided as-is for now, but I plan to clean up the codebase and add detailed documentation in the future.
